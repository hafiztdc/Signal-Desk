# Signal Desk

A mobile-friendly dashboard for MT5 TradeSignal files. Open index.html in Chrome or Edge to see the demo. Click **Connect MT5 folder** and select **MQL5 > Files > TradeSignals** to display your own pending orders, fills, and SL/TP changes on this PC.

The dashboard reads files locally in your browser. Demo pips, multiple targets and stats are sample data. Visitors to a hosted copy see the demo unless they connect their own local folder.

## GitHub Pages

Upload index.html and this README to the repository root. In **Settings > Pages**, choose **Deploy from a branch**, then **main** and **/(root)**. GitHub shows the URL after deployment.
